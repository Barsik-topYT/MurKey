# MurKEY-Manager 

An automation script for system administrators designed to manage Volume Licensing settings using the built-in Microsoft KMS toolkit.

##  Usage
The program automates calls to the standard Windows system utility slmgr.vbs to bind a node to KMS servers.

## ⚠️ Disclaimer
This project is created solely for educational purposes to demonstrate the operation of KMS protocols within isolated test networks. The developer does not provide a KMS infrastructure and is not responsible for the use of this utility.
